Tilemap and Texture Classes

Texture

Handles loading BMP images as SDL_Textures and supports rendering with transparency (color key for black).

Tilemap

Handles reading a tile layout from JSON metadata and rendering individual tiles from a texture atlas.

BrushButton Class

BrushButton allows selecting different brush types used for painting tiles onto the grid. Inherits from Button. Highlights the button with a red border when selected.

Key Methods

  • Clicked: Sets the brush type on click.
  • Dragged: Placeholder for drag behavior.
  • Render: Renders a red border if the button is selected.

SceneButton Class

SceneButton lets the user select which scene (level) is active for editing. Inherits from Button.

Key Fields and Methods

  • sceneNum: The scene number associated with this button.
  • sceneSetter: Delegate callback to change the active scene.
  • Clicked: Calls sceneSetter to update the scene.
  • Render: Highlights the button if its scene is active.

Editor Class

The main application class for the level editor. Manages loading, saving, rendering scenes, and handling UI interactions.

Core Responsibilities

  • Initialization: Loads background, tilemap, buttons, and scene buttons.
  • PlayClicked: Saves the current scene and triggers application switch.
  • SwitchScene: Saves current scene, loads another scene.
  • LoadScene: Loads scene JSON into the grid.
  • SaveCurrentScene: Serializes the current grid into a JSON file.
  • Input: Processes SDL input events and forwards them to the UI.
  • Render: Draws the background and UI components.
  • Tick: Renders and processes input each frame.
  • Start/Stop: Load and save the scene at editor startup and shutdown.

Grid Class

Grid manages the interactive tilemap where users paint with different brushes to edit levels. Inherits from Button.

Responsibilities

  • Clicked: Handles placing tiles according to the current brush.
  • BrushToIndex: Maps brush type to tile type with additional checks for special tiles (start, end, spikes, arrows).
  • RecalculateTile/RecalculateSurroundings: Updates neighboring tiles intelligently after a tile change.
  • Render: Draws all tiles and overlays the visual grid lines.

UserInterface and Button Classes

Button

A basic clickable and draggable UI element. Used as the base class for BrushButton, SceneButton, and Grid.

UserInterface

Manages a collection of buttons. Processes clicks and drag events, and forwards rendering calls to all buttons.

Key Methods

  • AddButton: Adds a new button to the UI.
  • CheckClick: Detects clicks and drags on buttons.
  • Render: Calls Render on all buttons.
