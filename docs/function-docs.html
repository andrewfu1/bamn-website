Level Editor & Game Engine API

This documentation describes the core modules and types used in the custom SDL-based level editor engine.

Modules

  • User Interface
  • Brush Button
  • Scene Button
  • Tile Grid
  • Editor
  • TileMap & Texture

User Interface

Module: LevelEditor.UI

A lightweight UI manager that stores and manages interactive buttons.

  • Button – Base class for all clickable elements. Defines onClick and onDragOver.
  • UserInterface – Stores buttons and dispatches input/render events to them.

Brush Button

Module: LevelEditor.brushbutton

Specialized UI button used to select brush types. Highlights when selected.

  • BrushButton – Inherits from Button. Sets the active brush pointer when clicked.

Scene Button

Module: LevelEditor.buttons

Represents buttons that switch between scenes.

  • SceneButton – Calls a delegate to switch scenes and highlights when selected.

Tile Grid

Module: LevelEditor.grid

Handles the drawing and editing of the level’s tile grid using brush interactions.

  • Supports auto-blending for platforms using binary rules.
  • Only one start and one end tile allowed per scene.

Editor

Module: LevelEditor.editor

Main application class that initializes the grid, UI, and handles scene management.

  • Initializes all buttons (brushes, scenes, play).
  • Handles input and rendering each frame.
  • Reads/writes level state from/to JSON files.

TileMap & Texture

Module: LevelEditor.tilemap

Manages tiled texture rendering and parsing of tile metadata.

  • Texture – Loads BMP images and renders them with colorkey transparency.
  • Tilemap – Uses a JSON metadata file to extract and manage tile source rectangles.
