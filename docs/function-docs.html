User Interface

Module: LevelEditor.UI

A lightweight UI manager that stores and manages interactive buttons.

  • Button – Base class for all clickable elements. Defines onClick and onDragOver.
  • UserInterface – Stores buttons and dispatches input/render events to them.

Brush Button

Module: LevelEditor.brushbutton

Specialized UI button used to select brush types. Highlights when selected.

  • BrushButton – Inherits from Button. Sets the active brush pointer when clicked.

Scene Button

Module: LevelEditor.buttons

Represents buttons that switch between scenes.

  • SceneButton – Calls a delegate to switch scenes and highlights when selected.

Tile Grid

Module: LevelEditor.grid

Handles the drawing and editing of the level’s tile grid using brush interactions.

  • Supports auto-blending for platforms using binary rules.
  • Only one start and one end tile allowed per scene.

Editor

Module: LevelEditor.editor

Main application class that initializes the grid, UI, and handles scene management.

  • Initializes all buttons (brushes, scenes, play).
  • Handles input and rendering each frame.
  • Reads/writes level state from/to JSON files.

TileMap & Texture

Module: LevelEditor.tilemap

Manages tiled texture rendering and parsing of tile metadata.

  • Texture – Loads BMP images and renders them with colorkey transparency.
  • Tilemap – Uses a JSON metadata file to extract and manage tile source rectangles.

GameObject System

Module: GameCode.gameobject

  • GameObject – Core entity that owns components.
  • GameObjectFactory – Metaprogrammed function for building GameObjects with component sets.
  • MakeSprite, MakeCollider – Useful aliases for common factory setups.

Component System

Module: GameCode.component

  • IComponent – Base class inherited by all components.
  • TextureComponent, SpriteComponent, InputComponent – Core render/input/anim logic.
  • TransformComponent – Stores and updates object position and rotation.
  • ColliderComponent – Axis-aligned bounding box collider with collision check support.

Scene System

Module: GameCode.scene

  • Scene – Manages a tilemap and collection of GameObjects. Loads data from JSON maps.
  • LoadSceneFromJson – Parses tilemaps and populates object data.
  • MakePlayer, MakeShooter, MakeSpike, etc. – Factory methods for populating standard entities.

Game Application

Module: GameCode.gameapplication

  • GameApplication – Main loop handler for scene switching and game updates.
  • Tick() – Handles frame advancement (input → render → update).

Resource Manager

Module: GameCode.resourcemanager

  • ResourceManager – Singleton that manages image loading and deduplication.
  • Automatically loads SDL_Textures and stores them by filename.

Tilemap Components

Module: GameCode.tilemapcomponents

  • TilemapSprite – Efficient renderer for large tile-based maps.
  • TilemapCollider – Efficient grid-based collision checker (wall-based).
