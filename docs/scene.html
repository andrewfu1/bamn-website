GameState

Description: Stores simple key-value integer game state.

Fields

  • int[string] mIntMap - Maps a string key to an integer value.

Scene

Description: Represents a scene containing game objects, a tilemap, and associated state.

Fields

  • GameObject[] gameObjects - List of all active GameObjects in the scene.
  • GameState mGameState - Global state information for the scene.
  • SDL_Renderer* mRendererRef - Reference to the SDL_Renderer for drawing operations.
  • GameObject tilemap - GameObject representing the tilemap.
  • bool mActive - Whether the scene is currently active.

Scene Methods

  • this(SDL_Renderer* r, int sceneIndex): Constructs a Scene and loads it from a JSON file.
  • GameObject MakePlayer(SDL_Point location): Creates and returns a player GameObject at a specified location.
  • void LoadSceneFromJson(string filename): Loads a scene from a JSON file, creating GameObjects based on tile definitions.
  • void Input(SDL_Event e): Passes an SDL input event to all GameObjects in the scene.
  • void Update(): Updates all GameObjects and performs collision detection and cleanup.
  • void Render(): Renders all GameObjects in the scene.
  • void AddGameObject(GameObject go): Adds a GameObject to the scene.
