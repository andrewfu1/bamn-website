Summary

These components are just for the background and platform tiles of the tilemap. This could be done with ordinary colliders, but that's inefficient for static environments.

TilemapSprite

Description: A component that renders a static tilemap background using a texture atlas.

Fields

  • tiles: 2D array representing tile indices at each grid location.
  • mFrames: List of source rectangles for each tile.
  • mRendererRef: SDL_Renderer reference for drawing.
  • mTextureRef: Reference to the TextureComponent providing the tilemap texture.

Methods

  • this(GameObject owner): Constructs a TilemapSprite attached to a GameObject.
  • LoadMetaData(string filename): Loads tile layout metadata from a JSON file.
    Params: filename - Path to the JSON file.
  • Render(): Renders the full tilemap to the screen.
  • RenderTile(int index, SDL_Rect* location): Renders a single tile based on its index.
    Params: index (tile index), location (destination rectangle).

TilemapCollider

Description: A component that handles collision detection against static tiles in the tilemap.

Fields

  • tiles: 2D array representing tile indices.

Methods

  • this(GameObject owner): Constructs a TilemapCollider attached to a GameObject.
  • GetWallCollisions(SDL_Rect* rect): Returns a list of wall collision rectangles intersecting a given rectangle.
    Params: rect - Rectangle to check collisions against.
    Returns: Array of SDL_Rects representing collisions.
